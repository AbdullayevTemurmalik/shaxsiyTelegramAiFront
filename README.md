# Telegram AI (JARVIS) — Modern Cyber Web Dashboard

Full-featured modern React + TypeScript + Vite + Tailwind CSS Web Dashboard for the Telegram AI Userbot & JARVIS Assistant.

## 🚀 Live Demo & Integration
- **Backend API:** `https://shaxsiytelegramai-production.up.railway.app`
- **Default Port:** `5173` (Local Dev)
- **Framework:** Vite + React 18 + Tailwind CSS + Lucide Icons

## ⚙️ Environment Configuration
Create a `.env` file or configure Vercel Environment Variables:
```env
VITE_API_URL=https://shaxsiytelegramai-production.up.railway.app
```

## 🛠️ Scripts
- `npm install` — Install dependencies
- `npm run dev` — Start local Vite development server
- `npm run build` — Type-check with TypeScript and build for production
- `npm run preview` — Locally preview the production build

## 📦 Vercel Deployment
1. Connect this GitHub repository (`shaxsiyTelegramAiFront`) to Vercel.
2. Build command: `npm run build`
3. Output directory: `dist`
4. Set Environment Variable: `VITE_API_URL=https://shaxsiytelegramai-production.up.railway.app`
5. Click **Deploy**!
